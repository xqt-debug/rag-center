## 已验证的主要行为

- 验证码单次使用、错误次数限制、网页登录、CSRF、退出失效。
- 测试账号密码登录、自定义账号密码、错误凭证拒绝、重复登录保留知识库、健康检查不暴露密码，以及生产环境不注册测试入口。
- 用户名与手机号可空迁移升级后，已有手机号用户及其知识库归属保持完整。
- 知识库完整增删改查与修订冲突。
- 文件上传、读取、改名、版本替换、下载、删除与失败重试。
- 用户隔离、只读密钥、完整管理密钥、自建知识库授权、撤销后拒绝访问。
- 请求幂等、删除后重放请求限制、任务重启恢复、索引重复执行不产生重复片段。
- 关键词、向量和混合检索流程；向量服务失败时关键词降级。
- 文本 PDF 提取与物理页码引用，无文本 PDF 明确提示 OCR。
- 新版本处理成功后的切换、处理失败时旧版本保留、旧片段失效提示。
- 冻结初始迁移的升级、回退、再次升级。
- 官方 Python MCP 客户端通过实际 HTTP 完成连接、工具发现、知识库和文件 CRUD、检索及密钥撤销验证。
- 浏览器完成账号密码登录、创建知识库、上传资料、预览、关键词检索、创建管理密钥、生成配置、撤销与删除。
- 重构后的领域拆分与统一操作注册表通过实际 HTTP/MCP 回归，工具数量和权限行为保持一致。
- 不完整的向量返回不发布部分索引；失去 claim 的旧 worker 不能发布或覆盖新 worker 的错误状态。
- 后台循环遇到临时数据库故障后继续处理，日志不包含异常里的敏感正文。
- PDF 总页数包含尾部空白页；空上传对象标识与无效服务配置在入口拒绝。

- 未发送真实短信；验证码通过开发适配器验证，短信 webhook 的真实送达依赖外部服务配置。
