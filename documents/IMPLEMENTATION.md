# 第一版实现说明

更新日期：2026-11-16。本文记录当前代码行为；PRD 中的规划不自动表示已经实现。

代码已按业务领域和前端页面拆分；职责、扩展方法及事务／租约约束见 [维护指南](MAINTAINING.md)。

## 已实现

- 开发环境使用可配置的固定账号密码登录，默认 `admin / admin123`；首次登录创建独立用户，重复登录复用同一账户和资料，测试账号无需绑定手机号。
- 生产环境不注册测试账号密码入口，也不接受开发账号密码认证；正式手机号验证码流程保留。

- 中国大陆手机号验证码登录，首次自动注册、验证码单次消费、错误次数限制、手机号与 IP 限流、可撤销会话和网页 CSRF 检查。
- 开发随机验证码与短信 webhook 适配，生产配置检查。
- 知识库创建、分页查询、改名、描述更新和级联删除。
- TXT、Markdown、文本 PDF 上传，UTF-8 与 PDF 文件头校验，按账户统计存储与文件数量配额。
- PNG、JPEG、GIF、WebP、BMP 上传与原样下载；真实图片格式及解码上限校验、短期鉴权原图预览、动画保留。
- 本地 RapidOCR 中英文识别并接入现有文本检索；动图最多均匀抽取 12 帧、整帧文字去重并保留原帧号引用。未识别到文字时为 `stored`，原图可用但不计入索引完成。
- 网页“粘贴文本”入口支持直接输入或粘贴内容，保存为 TXT／Markdown 后索引、读取、编辑及下载。
- 文件元数据读取、分段文本预览、改名、整体内容替换、原文件下载、删除和失败重试。
- 持久化处理任务、租约与续租、进程重启恢复、有限向量服务重试、版本发布与并发修订检查。
- PostgreSQL pgvector 精确向量检索、Python 中文分词 + PostgreSQL 全文索引、RRF 混合排名。第一版先建立精确检索基线，没有添加 HNSW 近似索引。
- 同用户、同内容与同配置的向量复用；当前没有跨用户内容缓存。
- 只读／完整管理密钥模板、可选操作权限、明确知识库范围、到期与撤销、仅一次展示完整密钥、配置复制下载。
- 使用官方 SDK 的 Streamable HTTP MCP，共 18 个工具；MCP 与网页共用业务和权限服务。
- `create_image_document` 可一次提交 Base64 图片与非空正文，也支持上传凭证与正文联合保存；跳过自动 OCR，持久化正文并与原图绑定至同一版本，沿用异步索引、授权和幂等机制。
- 绑定目标的短期上传会话、下载时重新鉴权、写操作幂等、成功操作审计。
- 前端账户、知识库、文件管理、搜索实验室、MCP 接入、用量与最近操作记录。
- 文件列表展示真实索引阶段、“索引已完成”、文本块数量及发布完成时间，统计本页索引状态并提醒新完成文档；活跃任务每 3 秒更新，空闲时每 15 秒检查外部提交的任务。

## 第一版实现边界

- 本地测试向量仅用于开发演示；真实语义质量需配置外部 Embedding 后使用真实语料评估，不能把测试向量的流程通过当作语义效果通过。
- 默认使用真实向量服务，缺少密钥会明确失败。显式 `local-test` 产物标为“测试索引（非模型）”，不计入真实完成。更换向量服务、模型或维度后，可点击“重建索引”，无需重新上传；发布成功前保留旧版，语义搜索仅使用与当前配置兼容的索引。
- 短信目前通过 webhook 对接，未直接绑定阿里云／腾讯云 SDK；真实短信送达尚需供应商账号和网关。
- 文件存储目前是本地目录；对象存储适配器、分布式部署暂未实现。
- 文本更新为全文替换，尚无局部文本补丁、历史版本浏览或回滚。
- 没有回收站。删除立即关闭访问，worker 定期物理清理；原文历史版本在文档存续期间保留并计入存储额度。
- PDF 解析限制 500 页、提取文本 200 万字符、最多 5000 个文本块。解析预览展示提取文本与片段数，没有逐页渲染或复杂表格质量判断。
- 图片 OCR 不包含扫描 PDF OCR、图片语义理解、公式或表格结构恢复；手写与复杂布局识别需要核对原图。没有其他 Office 文件、重排模型、团队共享、计费套餐和 OAuth。
- 混合检索支持向量服务失败时降级为关键词检索；数据库不可用时整体报错，不伪装为无结果。
- 当前错误率与供应商费用没有独立统计面板；页面展示存储、文件数、片段数、队列、失败数以及成功管理操作。未实现检索用量计费。
- 现有密钥权限不提供在线编辑；需要改变授权范围或操作权限时创建新密钥并撤销旧密钥。
- 上传下载链接属于短期传输凭证；Agent 需具备 HTTP 文件传输能力。支持客户端模板示意，真实桌面客户端适配名单仍待确定。
- 单进程开发模式包含后台 worker；生产必须独立运行 API、worker 并通过迁移管理数据库。

## 后续优先项

1. 确定短信、Embedding 服务与目标 Agent，完成真实服务及客户端验收。
2. 建立代表性语料的检索评估集，测量召回、精确编号查询和延迟。
3. 提供对象存储、历史版本保留策略和运行日志维护任务。
4. 根据实际文本量和延迟决定是否添加近似向量索引与重排。
5. 按使用反馈增加局部文本更新、回收站和细化用量统计。
